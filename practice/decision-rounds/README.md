## Play a round

Answer without opening the explanation. Give a reason for rejecting each other option, then compare your reasoning. Afterward, complete the small challenge or describe the evidence you would need if you do not have a sandbox available.

For a harder round, change one requirement so the original answer no longer fits. The goal is explaining the decision, not accumulating a score. No result here predicts an exam pass.

## Anki import

Download [decision-rounds.tsv](decision-rounds.tsv). It has 14 cards and no header row. Import it as tab-separated text with a Basic note type. Map columns to Front, Back, and Tags, and enable HTML in fields. Preview a card before importing.

Each front includes the question and all choices. Each back repeats the choices and explains the correct and incorrect options. Domain tags let you focus on one topic.

This is a separate deck. The existing 35-question CLI quiz, its Anki deck, and the ten visual recall cards are unchanged.
