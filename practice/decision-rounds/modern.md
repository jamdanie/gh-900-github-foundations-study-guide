## 1. A developer needs a browser-based environment that can execute project tools. Which choice fits better than github.dev alone?

A. A repository star

B. A Codespace

C. A Markdown heading

D. A milestone

<details>
<summary>Answer and explanations</summary>

Correct answer: **B**.

- A. A star saves or signals interest in a repository.
- B. Codespaces provides hosted compute for development; github.dev alone is a browser editor.
- C. Formatting a document does not supply an execution environment.
- D. A milestone groups work rather than running it.

</details>

## 2. A workflow step uses run: to execute a Python command. What should you inspect to know whether that execution succeeded?

A. The AI message that suggested it

B. The repository's star count

C. The step result and output for the relevant run

D. Only the workflow's name

<details>
<summary>Answer and explanations</summary>

Correct answer: **C**.

- A. A suggestion is not an execution record.
- B. Stars do not report command results.
- C. The relevant step output and result provide evidence about that execution.
- D. A name describes the workflow but does not show what happened.

</details>
