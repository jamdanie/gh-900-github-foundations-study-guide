## 1. A Project should group tasks into repeating two-week study periods. Which field fits that requirement?

A. Iteration

B. Repository visibility

C. Default branch

D. Release asset

<details>
<summary>Answer and explanations</summary>

Correct answer: **A**.

- A. Iterations associate work with repeating time blocks.
- B. Visibility controls the audience, not scheduling periods.
- C. A default branch is a repository setting, not a planning field.
- D. An asset belongs to a release rather than a recurring schedule.

</details>

## 2. The same Project items should be inspected by status and by planned timing. What is the appropriate approach?

A. Create duplicate issues for each layout

B. Use suitable board and roadmap views

C. Close all issues before changing the layout

D. Change each issue into a repository

<details>
<summary>Answer and explanations</summary>

Correct answer: **B**.

- A. Duplicating tasks makes multiple records for the same work unnecessarily.
- B. Views can display the same underlying items for different planning questions.
- C. Closing work is not a prerequisite for choosing a planning layout.
- D. An issue and a repository are different kinds of objects.

</details>
