## 1. You want notifications for one issue conversation without watching all repository activity. What best fits?

A. Subscribe to that issue

B. Create a release

C. Rename the default branch

D. Clone the repository again

<details>
<summary>Answer and explanations</summary>

Correct answer: **A**.

- A. A thread subscription targets that conversation.
- B. A release packages a version; it does not subscribe you to this issue.
- C. Renaming a branch does not select conversation notifications.
- D. Another clone does not configure GitHub thread notifications.

</details>

## 2. In GitHub issue and PR search, you want open PRs that request your review. Which query fits?

A. is:issue is:open assignee:@me

B. is:pr is:merged

C. is:pr is:open review-requested:@me

D. is:issue label:documentation

<details>
<summary>Answer and explanations</summary>

Correct answer: **C**.

- A. This searches assigned open issues, not requested PR reviews.
- B. This searches merged PRs instead of pending reviews.
- C. This selects open PRs requesting your review.
- D. This selects labeled issues and does not express the review request.

</details>
