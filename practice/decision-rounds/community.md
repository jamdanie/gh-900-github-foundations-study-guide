## 1. Teams use contribution guidance, branches, and PR reviews inside an organization without publishing the code. What practice does this illustrate?

A. InnerSource

B. Public-domain licensing

C. GitHub Pages hosting

D. A local stash

<details>
<summary>Answer and explanations</summary>

Correct answer: **A**.

- A. InnerSource applies open-source collaboration practices within an organization.
- B. The scenario does not establish a public-domain license.
- C. The scenario describes collaboration, not a website.
- D. A stash temporarily stores local work and is not an organization collaboration model.

</details>

## 2. You want to financially support an eligible open-source maintainer. Which feature is intended for that?

A. Starring the repository

B. Watching every issue

C. GitHub Sponsors

D. Creating another branch

<details>
<summary>Answer and explanations</summary>

Correct answer: **C**.

- A. A star is not a payment.
- B. Watching configures notifications rather than financial support.
- C. Sponsors is designed for financial support of eligible contributors.
- D. A branch organizes work rather than transferring support.

</details>
