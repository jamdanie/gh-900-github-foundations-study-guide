# Review log: choose the next useful session

Use this method in your own notes. It is a study tool, not proof of certification readiness. Do not enter passwords, tokens, or private repository information.

## Record the gap precisely

After an exercise, record the topic, your initial reasoning, the correction, and one task that would demonstrate the difference. A note such as “Git is confusing” is hard to act on. A note such as “I thought fetch changed my current branch” tells you what to revisit.

## Worked example

This is a fictional learning example, not a result claimed by the author.

| Part | Example |
| --- | --- |
| Topic | Fetch versus pull |
| Initial reasoning | I expected fetch to update the file I had open |
| Correction | Fetch retrieves remote history; it does not integrate that work into the checked-out branch |
| Source to revisit | The command dictionary and Git step-by-step guide |
| Next task | Explain which branch changes after a fast-forward pull in the editor lab |
| Evidence to record | Commands actually run, relevant output, and the explanation of the result |

## Use the result

If you cannot explain the term, read its chapter and define it in your own words. If you can define it but choose the wrong feature, compare two scenarios that differ in one requirement. If you choose correctly but cannot perform the task, use the matching lab and inspect each result.

After another topic, return to the earlier gap with a new example. Do not count repeated recognition of an answer as proof that you can apply it. If AI supplies a new example, verify its explanation against the linked documentation before recording it as a correction.
