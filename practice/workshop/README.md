# Beginner documentation workshop

[Table of contents](../../CONTENTS.md) · [Hands-on challenges](../hands-on-challenges/README.md)

Use these six exercises to turn a game observation or lab result into material another learner can follow. Read the situation, decide before opening the explanation, and complete the small task. No purchase is required. The scenarios are fictional and separate from the existing quizzes and Anki decks.

1. [Make a report reproducible](01-reproduce-a-report.md)
2. [Split a task without losing its purpose](02-separate-tasks.md)
3. [Choose the explanation a beginner can use](03-compare-explanations.md)
4. [Write a handoff someone can continue](04-inspect-a-handoff.md)
5. [Check whether a game supports a study claim](05-review-a-game-claim.md)
6. [Choose the next correction](06-prioritize-corrections.md)

## Choose a resource

Use the [visual learning resource guide](../../docs/visual-learning-resources.md) for the existing Steam game listings and free Git alternatives. For these workshops, supplied observations work just as well as a game session. Describe publisher claims as publisher claims and your own observations as observations.

## Complete a session

Start with the reproducible report, then choose either the handoff or correction exercise. Write your answer before inspecting the worked explanation. Save only what you actually did in your practice record. If you use your own sandbox repository, review the change before publishing it.

Use the [command dictionary](../../docs/command-dictionary.md) for command meanings and the [browser editing challenge](../hands-on-challenges/01-browser-edit.md) if you do not have a local Git setup.
