# Make a report reproducible

[Workshop menu](README.md)

## Situation

A fictional simulator note says: “The connection broke. Please fix.”

## Decide first

List the missing information before suggesting a fix.

<details>
<summary>Worked explanation</summary>

The report needs the starting configuration, the action, expected and actual results, and whether the result repeats. A screenshot can help, but it does not replace the sequence.

</details>

## Try it

In your sandbox, write an issue with numbered reproduction steps using the supplied fictional observation: the display is Connected; one link is removed; the display changes to Disconnected; restoring the link returns Connected.

Finish check: A reader can repeat the stated sequence. Label this as fictional unless you actually perform it.

## Change the situation

What would you change if the failure appeared only once? Record that uncertainty and avoid claiming reliable reproduction.

These are original practice situations, not recalled exam questions or claims about the author's experience.
