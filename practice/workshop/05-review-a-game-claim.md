# Check whether a game supports a study claim

[Workshop menu](README.md)

## Situation

A fictional recommendation says: “Finishing a data-center game proves you are ready for GH-900.”

## Decide first

Identify the missing connection between the activity and the conclusion.

<details>
<summary>Worked explanation</summary>

The recommendation provides no evidence that the game measures GitHub knowledge. A game can supply an observation to document, but exam preparation also requires the actual GitHub topics and practice.

</details>

## Try it

Pick a resource from the visual learning guide. Name one activity it supports, one GitHub task you can do afterward, and one topic you still need to study elsewhere. Do not buy a resource to complete this exercise.

Finish check: Your recommendation describes a specific use and a limitation without making a pass guarantee.

## Change the situation

If you have not played it, how should you describe it? Attribute features to its publisher and distinguish those descriptions from personal testing.

These are original practice situations, not recalled exam questions or claims about the author's experience.
