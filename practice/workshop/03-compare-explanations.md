# Choose the explanation a beginner can use

[Workshop menu](README.md)

## Situation

Two fictional notes say: A: “Commit your work.” B: “Record the selected changes with a message explaining them, then check that the intended file appears in the commit.”

## Decide first

Which note gives the reader a way to detect a mistake? Explain what is still missing.

<details>
<summary>Worked explanation</summary>

B includes an inspection step. It still needs the specific interface or commands for the reader's environment. A beginner may not know where to perform the action.

</details>

## Try it

Choose one entry in the command dictionary and write a small example using a disposable file. Include the starting state, intended result, and what to inspect. Use the existing dictionary to verify command meaning before running it.

Finish check: Your example names the file and gives an observable result rather than saying only “success.”

## Change the situation

How would your explanation change for a browser-only learner? Point to the browser editing challenge instead of assuming a local terminal.

These are original practice situations, not recalled exam questions or claims about the author's experience.
