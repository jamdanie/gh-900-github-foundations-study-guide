# Write a handoff someone can continue

[Workshop menu](README.md)

## Situation

A fictional learner stops after creating a branch and writing a note, before opening a PR.

## Decide first

What should the next person know without repeating the entire session?

<details>
<summary>Worked explanation</summary>

They need the repository and branch, the saved state, what was checked, remaining work, and any unresolved question. “Almost done” does not identify a next action.

</details>

## Try it

Write a five-sentence handoff for that fictional state. State explicitly whether the note was committed. Name opening and reviewing the PR as remaining work rather than completed work.

Finish check: The recipient can identify the next action and distinguish completed work from planned work.

## Change the situation

If the note exists only in the editor, how does the handoff change? Preserve and commit the intended work before treating the branch as containing it.

These are original practice situations, not recalled exam questions or claims about the author's experience.
