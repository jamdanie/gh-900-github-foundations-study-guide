# Sort observations from explanations

[Visual drill menu](README.md)

This is an original fictional exercise. The table is supplied practice material, not a record of a real game session.

| Statement | Your classification |
| --- | --- |
| The indicator changed after the link was removed. | Observation |
| The missing link caused every later failure. | Untested explanation |
| Repeating the test could check consistency. | Proposed next step |

## Try it first

Hide the classification column and sort the three statements yourself. Then write one observation from a game or lab you actually used. Keep any explanation in a separate sentence.

<details>
<summary>Worked explanation</summary>

The first statement reports sequence, not a universal cause. The second reaches beyond the supplied evidence. The third describes future work, not a completed test.

</details>

## Apply it in GitHub

Turn your observation into the first paragraph of a sandbox issue. Give the next step its own task so readers can see that it is still pending.

Finish when you can explain your choice and point to the evidence that supports it. Use [the existing labs](../../CONTENTS.md#labs-in-order) for setup instructions.
