# Spot missing context in a screenshot

[Visual drill menu](README.md)

This is an original fictional exercise. The table is supplied practice material, not a record of a real game session.

| Visible item | What is still unknown? |
| --- | --- |
| A green status indicator | Which check or state it represents |
| A file named result.md | Which repository and branch contain it |
| A comment saying fixed | What changed and how it was checked |

## Try it first

Write a caption for each item that would resolve the missing context. Do not invent actual repository names, results, or checks; describe which information you need to inspect.

<details>
<summary>Worked explanation</summary>

Color alone does not name a check. A filename alone does not identify a version. A comment alone does not show verification. The useful next action is to inspect the associated context, then state what it actually shows.

</details>

## Apply it in GitHub

Use a screenshot from your sandbox, if available. Add a nearby text explanation naming the relevant state and limitation. Review the image for private information before publishing.

Finish when you can explain your choice and point to the evidence that supports it. Use [the existing labs](../../CONTENTS.md#labs-in-order) for setup instructions.
