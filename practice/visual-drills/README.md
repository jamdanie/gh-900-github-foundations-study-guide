# Visual reasoning drills

[Table of contents](../../CONTENTS.md) · [Visual resources](../../docs/visual-learning-resources.md)

These short table-based exercises connect observations, project work, and review decisions. They work without installing software or buying a game. Each has a worked explanation and a GitHub follow-up task.

1. [Sort observations from explanations](01-sort-observations.md)
2. [Read a board without guessing](02-read-a-task-board.md)
3. [Spot missing context in a screenshot](03-spot-missing-context.md)
4. [Match feedback to a repair](04-match-review-feedback.md)
5. [Choose an action after a missed question](05-choose-a-study-action.md)
6. [Build a session map from evidence](06-build-a-session-map.md)

Read the prompt before the explanation. Hide a table's answer column when asked, make your choice, and explain why. These are original exercises, separate from the quiz and Anki decks; they do not predict an exam result.

For a game session, start with observation sorting and end with the session map. For a repository session, use the board and review drills. The [documentation workshops](../workshop/README.md) provide longer follow-up tasks.
