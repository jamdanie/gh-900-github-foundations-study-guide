# Build a session map from evidence

[Visual drill menu](README.md)

This is an original fictional exercise. The table is supplied practice material, not a record of a real game session.

| Session step | Output |
| --- | --- |
| Predict | One written expected result |
| Try | One action in a sandbox or simulation |
| Inspect | A specific result you observed |
| Explain | A reason and a limitation |
| Share | A reviewed note another learner can follow |

## Try it first

Choose a small task from the visual learning guide. Describe what you would produce at each step. If you cannot use a tool, use a supplied fictional case and label it as supplied data.

<details>
<summary>Worked explanation</summary>

The map separates plans, actions, and evidence. A prediction is not an observation. Sharing a note is not proof that every explanation is correct; inspect its claims before publishing.

</details>

## Apply it in GitHub

Complete one session in your own sandbox. Keep an unanswered question in the record so your next session has a clear starting point. No paid game is required.

Finish when you can explain your choice and point to the evidence that supports it. Use [the existing labs](../../CONTENTS.md#labs-in-order) for setup instructions.
