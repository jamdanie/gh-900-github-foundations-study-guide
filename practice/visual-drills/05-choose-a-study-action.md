# Choose an action after a missed question

[Visual drill menu](README.md)

This is an original fictional exercise. The table is supplied practice material, not a record of a real game session.

| Difficulty | Useful next action |
| --- | --- |
| I do not recognize a term. | Read its definition and find it in an example. |
| I recognize the term but choose the wrong feature. | Compare the scenario requirements with each choice. |
| I choose correctly but cannot explain why. | Explain the decision without looking at the answer. |

## Try it first

Use one original practice question from this guide. Identify which difficulty best describes your attempt. Write a next step that addresses it.

<details>
<summary>Worked explanation</summary>

Different mistakes need different practice. Repeating an answer letter does not resolve confusion between features. A changed scenario can reveal whether the reason for the choice is understood.

</details>

## Apply it in GitHub

Use the chapter decision rounds for a changed requirement. Record the reason you changed your answer, not just whether the answer was marked correct.

Finish when you can explain your choice and point to the evidence that supports it. Use [the existing labs](../../CONTENTS.md#labs-in-order) for setup instructions.
