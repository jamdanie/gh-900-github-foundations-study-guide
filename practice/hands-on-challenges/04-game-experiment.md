# Challenge 4: Change one thing in a simulation

[Challenge menu](README.md) · [Resource choices](../../docs/visual-learning-resources.md)

Use a game you already have, a free Git visualization, or the fictional results below. No purchase is required. Choose only controls your selected resource actually provides.

## Plan before clicking

Choose a visible outcome, such as a displayed connection state or the position of a branch label. Record the starting state. Predict what one action will change, then perform it and record what happened.

Keep the starting configuration and workload unchanged where possible. If several things change at once, record that limitation instead of choosing a cause from the result alone.

## Free paper exercise

These are invented results, not measurements from either Steam title.

| Trial | Changed condition | Displayed result |
| --- | --- | --- |
| A | None; initial setup | Connected |
| B | One link removed | Disconnected |
| C | Same link restored | Connected |
| D | Link removed and workload changed together | Disconnected |

Which trials give the clearest comparison for the effect of removing that link?

<details>
<summary>Worked answer</summary>

A and B provide the clearest before-and-after comparison in the supplied setup. C adds a recovery observation. D changes two conditions, so it cannot isolate their individual effects. None of these trials establishes how every possible configuration behaves.

</details>

## Bring it back to GitHub

Create a note in your sandbox with the starting state, action, observation, and limitation. Open an issue for one unanswered question, then propose the note through a PR. The GH-900 practice is organizing and reviewing the evidence.

Finish when another reader can distinguish the supplied fictional data from anything you personally tested.
