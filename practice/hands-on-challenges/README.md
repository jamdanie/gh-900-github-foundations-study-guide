# Hands-on challenge pack

[Full table of contents](../../CONTENTS.md) · [Practice formats](../README.md)

Choose a task, predict what will happen, and inspect the result. Each challenge includes a finish check or worked explanation. These are original exercises, separate from the 35-question quiz and the existing Anki decks.

| Challenge | What you practice | Setup |
| --- | --- | --- |
| [1. Where is the saved change?](01-browser-edit.md) | Editing, branches, commits, and browser storage | GitHub account and your own disposable repository |
| [2. Find the exact version](02-file-detective.md) | Raw view, Blame, diffs, and permanent links | Read-only browser access |
| [3. Review the meaning of a change](03-review-the-diff.md) | Specific feedback and limits of automated checks | Supplied fictional diff |
| [4. Change one thing in a simulation](04-game-experiment.md) | Predictions, observations, and fair comparisons | Supplied data, free visual tool, or a game you own |
| [5. Give a board card a finish condition](05-project-acceptance.md) | Issues, Projects, acceptance criteria, and evidence | Your own sandbox and Project |
| [6. Make AI test your reasoning](06-ai-teach-back.md) | Changed requirements and source checking | Optional AI or a study partner |
| [7. Make visual evidence readable](07-readable-evidence.md) | Captions and text alternatives | Supplied example or your own image |
| [8. Check progress with evidence](08-progress-check.md) | Self-assessment and contribution attribution | One completed challenge |

## Pick a session

For a reading-only session, try challenges 2, 3, and 7. For an actual repository change, combine 1 and 5. For a game session, combine 4 and 7, then track the documentation using 5.

Start with [free Git visualizations](../../docs/visual-learning-resources.md) if you want software practice without buying a game. The Steam titles are optional infrastructure simulations. You can complete the supplied fictional exercise without either title.

## Keep the record honest

Write what you predicted, what you did, what you saw, and what you still cannot conclude. Label supplied data as fictional. Label solo inspection as self-review. Use [challenge 8](08-progress-check.md) to choose the next step from what you can explain, not just what you clicked.

The exercises support parts of GH-900 study; they do not replace the [exam outline](../../docs/exam-outline.md) or establish readiness for every objective.

## Continue with documentation practice

The [six beginner workshops](../workshop/README.md) help you turn an observation into a reproducible report, a clear handoff, or a targeted correction. Each includes a fictional situation, worked explanation, task, and changed condition.
