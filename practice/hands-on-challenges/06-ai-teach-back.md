# Challenge 6: Make AI test your reasoning

[Challenge menu](README.md) · [Prompt dictionary](../../docs/copilot-prompts.md)

Use your own notes or original practice material. These are ordinary prompts, not guaranteed Copilot slash commands. No paid AI subscription is required; a study partner can ask the same questions.

## Ask one question at a time

> Ask me an original beginner question about branches and pull requests. Wait for my answer. Ask why I chose it before explaining the answer. Do not use recalled certification questions.

After answering:

> Change one requirement in that scenario so a different next step makes sense. Ask me what changes and why. Wait for my answer.

After explaining:

> Identify any product claim in my answer that needs verification. Suggest which official documentation topic to inspect. Do not invent a quotation or claim that a command ran.

## Worked change of requirement

First task: explain a documentation change before it reaches the default branch. A PR lets you inspect and discuss the proposed change.

Changed task: inspect the exact version someone reviewed last week. A commit-specific file link addresses that need. A link to a changing branch doesn't fix the version.

## Check the explanation yourself

Open the relevant source and compare its wording with the claim. For a command, inspect what it would do before trying it in a disposable repository. Record only results you actually observe.

Finish by explaining the decision without looking at the AI response. If you only remember the answer letter, ask for a new situation.

This extends the study method described in [my study approach](../../docs/my-study-approach.md); it does not claim these exact prompts were used before the exam.
