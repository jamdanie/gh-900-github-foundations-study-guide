# Challenge 7: Make visual evidence readable

[Challenge menu](README.md) · [Diagram lab](../../labs/14-explain-with-a-diagram.md)

Goal: make a visual observation understandable without requiring readers to interpret color alone. Use your own sandbox screenshot or the fictional example below.

## Inspect what the image needs to explain

A screenshot of a red board card doesn't tell readers whether red means blocked, urgent, overdue, or something else. Write the status as text and name the action that changed it.

For a screenshot you plan to publish, inspect the complete image for unrelated personal details or credentials. Crop to the relevant area and verify that the remaining context still supports the claim.

## Rewrite this caption

Weak caption: “It worked.”

Fictional context: a note was added on a branch and the repository page now displays its commit.

Better caption: “The practice branch now contains the note and its commit. This view does not show that the branch was merged.”

Explain why the better caption is narrower: the image shows one branch, not the default branch's later state.

## Make a text equivalent

Record the repository or simulator, relevant state, action, and observed result in nearby prose. For a diagram, state the relationship it illustrates. A picture should support the explanation, not be the only place the answer exists.

Finish when a reader can understand the observation with images hidden. Keep the original evidence private if publishing it would expose information you cannot safely remove.
