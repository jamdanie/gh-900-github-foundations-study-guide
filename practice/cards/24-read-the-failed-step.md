# Read the failed step

Topic: Actions

A workflow run is red. What should you read before changing unrelated files?

<details>
<summary>Explanation</summary>

Open the failed job and step logs. Identify the reported failure and the commit being tested. A red run is evidence of a failed configured operation, not a diagnosis of every possible repository problem.

</details>

## Try a different angle

Write the observed failure and the proposed correction as separate statements.
