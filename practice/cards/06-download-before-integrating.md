# Download before integrating

Topic: Git

You want information about remote work before integrating it into your current branch.

<details>
<summary>Explanation</summary>

Use git fetch origin. Fetch updates remote-tracking information and downloads history. It does not merge that work into your checked-out branch. Inspect the result before choosing how to integrate.

</details>
