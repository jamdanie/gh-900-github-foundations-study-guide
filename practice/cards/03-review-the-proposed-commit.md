# Review the proposed commit

Topic: Git

You staged a correction. How do you check the exact content selected for the commit?

<details>
<summary>Explanation</summary>

Use git diff --staged. A plain git diff shows unstaged changes instead. A staged review helps catch accidental edits before they become part of history.

</details>
