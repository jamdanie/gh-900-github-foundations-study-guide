# Undo a published change

Topic: Git

An ordinary single-parent commit added incorrect wording and has already been shared. How can you reverse it while retaining history?

<details>
<summary>Explanation</summary>

A revert creates a new commit that reverses a selected commit. Review the result, since conflicts are possible. Reverting a merge has additional choices and is outside this small exercise.

</details>
