# An exposed token

Topic: Security and evidence

A real token was committed and then deleted from the visible file. Is the credential safe again?

<details>
<summary>Explanation</summary>

Deleting the line does not invalidate the token. Revoke or rotate the exposed credential and investigate the exposure. Secret scanning can help detect supported credential patterns. Never use a real credential to create this exercise.

</details>

## Try a different angle

Describe the difference between removing visible text and removing the token's ability to authenticate.
