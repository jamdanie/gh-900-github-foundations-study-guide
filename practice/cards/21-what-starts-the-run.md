# What starts the run

Topic: Actions

A workflow contains on: push. What event is it configured to respond to?

<details>
<summary>Explanation</summary>

A push event can start a run, subject to the workflow's filters and other conditions. The event is the trigger; the workflow defines the work. Reading only a job name does not tell you when it runs.

</details>
