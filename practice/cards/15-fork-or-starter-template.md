# Fork or starter template

Topic: Collaboration

You want an independent project from starter files, rather than contributing a fix upstream.

<details>
<summary>Explanation</summary>

A template is designed for creating a new project from reusable files. A fork retains a connection and upstream history for related development. Decide whether you want an independent starting point or a contribution relationship.

</details>
