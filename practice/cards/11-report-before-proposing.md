# Report before proposing

Topic: Collaboration

You find confusing instructions but do not yet have a correction. Where can you describe the problem?

<details>
<summary>Explanation</summary>

An issue can record the problem, observed result, and desired result. A PR proposes file changes. Reporting clearly gives a later editor enough information to address the right problem.

</details>

Write a two-sentence issue description without claiming you have already fixed it.
