# A view is not a duplicate task

Topic: Projects

You need a board for status and a table for comparing fields. Must you create each task twice?

<details>
<summary>Explanation</summary>

No. Multiple Project views can display the same items. Changing the layout changes how you inspect the work, rather than creating a separate issue for every view.
