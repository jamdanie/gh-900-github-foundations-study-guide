# Dependencies versus dependents

Topic: Security and evidence

Your app uses package A, and another project uses your published package. Which relationship is which?

<details>
<summary>Explanation</summary>

A is your dependency. The project using your package is a dependent. A transitive dependency comes through another dependency. Keeping the direction clear helps you interpret dependency information.

</details>
