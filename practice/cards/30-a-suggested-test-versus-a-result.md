# A suggested test versus a result

Topic: Security and evidence

AI gives you a test command and says it should pass. Have you verified the change?

<details>
<summary>Explanation</summary>

No. A proposed command is not an execution result. Run an appropriate check in your practice setup, inspect its output, and assess what it actually covers. Do not claim a result you did not observe.

</details>
