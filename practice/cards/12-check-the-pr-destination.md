# Check the PR destination

Topic: Collaboration

You are practicing in a fork. Before opening the PR, what destination should you check?

<details>
<summary>Explanation</summary>

Confirm the base repository and target branch. In these practice labs, the destination is your fork's main branch. A connected fork can also propose upstream changes, so do not assume the selected destination is your sandbox.

</details>
