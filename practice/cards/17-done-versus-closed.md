# Done versus closed

Topic: Projects

You moved a Project card to Done. What should you check before saying its issue is closed?

<details>
<summary>Explanation</summary>

Inspect the issue state and the Project automation. Project status and issue state are different properties; do not assume a status change closed the issue. Describe only the behavior you observed.
