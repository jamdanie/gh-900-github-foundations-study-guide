# Pause tracked work

Topic: Git

You have unfinished tracked edits and need to set them aside temporarily.

<details>
<summary>Explanation</summary>

A stash can save the tracked changes so you can resume later. Inspect status first. Untracked files are excluded by default; -u includes them. Reapplying a stash can still produce conflicts.

</details>
