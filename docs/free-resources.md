# Free resources and how to use them

These are selected for clear explanations, practical exercises, and identifiable authors or maintainers. This is a curated study route, not a claim that a resource has a measured pass rate. No paid course or question bank is required for this route.

| Resource | Best use | How to work with it |
| --- | --- | --- |
| [Microsoft Learn certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/) | Training and official practice assessment | Follow both learning paths; investigate missed concepts |
| [Current exam outline](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900) | Scope and domain weights | Compare it with older videos and notes |
| [GitHub Skills](https://github.com/skills) | Interactive exercises in real repositories | Start with Introduction to GitHub, then try an Actions exercise |
| [GitHub Docs](https://docs.github.com/en) | Current behavior, settings, and permissions | Verify one specific claim instead of reading everything at once |
| [freeCodeCamp: GitHub Foundations, Andrew Brown](https://www.freecodecamp.org/news/pass-the-github-foundations-certification-course) | Long-form demonstrations | Pick a topic, pause, and reproduce a small example |
| [Pro Git, Scott Chacon and Ben Straub](https://git-scm.com/book/en/v2) | Git concepts that remain confusing | Read the relevant basics or branching section, then try the commands |
| [Git command reference](https://git-scm.com/docs) | Exact command behavior | Check flags and side effects before running unfamiliar commands |
| [VS Code source control](https://code.visualstudio.com/docs/sourcecontrol/overview) | Editor workflow | Match each editor action to the Git operation |
| [Visual Studio Git documentation](https://learn.microsoft.com/en-us/visualstudio/version-control/git-with-visual-studio) | Visual Studio workflow | Use the Git Changes and Git Repository windows |

## Use the video with the current outline

The linked freeCodeCamp course was published January 31, 2024. It is useful for demonstrations but predates the January 2026 exam revision. Do not rely on its old domain weights, interface labels, or Copilot plan details as current. Check modern agent features, model choices, policies, and account security against current documentation.

The free video is the recommendation here. Purchases from its creator's separate training business are not part of this study route. I am not claiming this is the specific video James used.

## Keep the exercises free

The reading and linked public video are available without buying a course. Hosted services can still have usage limits or charges. Use local Python for this repo's runnable exercises if you do not want hosted compute. Codespaces and paid Copilot features are optional; the conceptual lessons and quiz do not require a subscription.

## Choose legitimate practice

Use official practice assessments and original questions that explain their reasoning. Skip collections advertised as actual exam questions, recalled questions, dumps, or guaranteed passes. A high score from recognizing repeated answers is not the same as understanding a new scenario.

A useful resource tells you what feature applies and why. If an explanation conflicts with current documentation, check its date and assumptions before turning it into a flashcard.

## Visual and interactive alternatives

For a browser Git simulator, an open-source Git game, and direct GitHub Skills course links, use the [visual learning resource guide](visual-learning-resources.md). Start with its free options and follow [lab 11](../labs/11-visual-git-challenge.md) to connect actions with observations.

The guide separately labels optional paid Steam simulations. They can supply scenarios for a GitHub documentation exercise, but they are not required resources or verified GH-900 training. No purchase is needed to complete the [observation-to-PR lab](../labs/13-observation-to-pull-request.md).
