# GH-900 topic outline and practice route

Use this checklist with the [official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900). It groups the January 2026 outline into study topics; the official guide controls scope. [Domain weights](exam-map.md) help prioritize review. Checking a box should mean you can explain the topic, not just recognize its name.

## 1. Git and GitHub basics

- [ ] Version control; repositories, commits, and branches.
- [ ] Git versus GitHub; personal, organization, and enterprise accounts.
- [ ] GitHub flow, Markdown, Desktop, and Mobile.

Practice: use [lab 1](../labs/01-git-and-editors.md) to move a note from a local branch into a merged PR. Write the note using a heading, list, link, and code block. Explain which steps require a hosting account and which work offline. Compare completing the task in an editor, Desktop, and a mobile collaboration workflow.

## 2. Repositories

- [ ] README, LICENSE, CONTRIBUTING, CODEOWNERS, and SECURITY.
- [ ] Templates, branches, file management, and maintenance.
- [ ] Insights, stars, previews, metrics, and dependencies.

Practice: use the [foundations reference](foundations-reference.md) to explain the job of each repository file. Propose one documentation change through a branch. Inspect the repository's available Insights and explain what the numbers can and cannot show. Compare starting from a template with contributing through a fork.

## 3. Collaboration

- [ ] Issues, PRs, discussions, and notifications.
- [ ] Linking, templates, filters, and assignments.
- [ ] Gists, Wikis, and Pages.

Practice: use [lab 3](../labs/03-project-board.md) to link a task to its change. Write a question that belongs in a discussion and a bug report that belongs in an issue. Find your assigned open work with a filter. Choose whether a short snippet, a documentation collection, or a static site fits each publishing feature.

## 4. Modern development

- [ ] Actions; Copilot agents, agent mode, models, and plans.
- [ ] Codespaces, dev containers, and github.dev.

Practice: complete [lab 2](../labs/02-environments-and-actions.md). Explain why the browser editor alone is different from a hosted execution environment. In the [Copilot guide](copilot-prompts.md), distinguish a text suggestion from an agent taking actions. Compare personal access with organization-managed policies using current plan documentation.

## 5. Project management

- [ ] Layouts, fields, labels, milestones, and workflows.
- [ ] Saved replies, assignees, and insights.

Practice: complete [lab 3](../labs/03-project-board.md), then add dates and a roadmap view. Explain how the timeline differs from the board. Build a saved reply for an unclear question and a filtered view for a weak exam domain. Describe what evidence would make you move an item to Done.

## 6. Privacy, security, and administration

- [ ] 2FA, passkeys, permissions, roles, and teams.
- [ ] Managed users, Copilot policies, visibility, and branch rules.

Practice: use [lab 4](../labs/04-team-management.md) for access decisions and [lab 6](../labs/06-profile-and-security.md) for account settings. Explain the difference between proving your identity and granting an application access. Inspect a branch requirement and distinguish it from an ordinary check that merely reports a result.

## 7. Community

- [ ] Open source, Sponsors, following, and Marketplace.
- [ ] InnerSource, forks, templates, and discoverability.

Practice: complete [lab 5](../labs/05-marketplace-and-ai.md). Find a project with clear contribution guidance and explain a small improvement you could propose. Compare a public contribution with the same workflow inside an organization. Explain why starring, following, and sponsoring are different actions.

## Extra practice and readiness

OAuth, detailed Git recovery, Python test implementation, and deployment-environment setup support understanding; they are not separate weighted domains. The account lab includes profile settings because they were part of James's preparation.

For each section, explain a concept without notes, complete a small task, and answer a fresh scenario. Revisit an earlier topic after studying another one. Use the [practice set](../practice/README.md) as a starting point and the official assessment for broader feedback. The starter set is not a comprehensive mock exam, and no score here guarantees readiness.

## More practice for common gaps

Use [common decisions](common-decisions.md) to compare similar features, [lab 7](../labs/07-markdown-and-triage.md) for Markdown and triage, and [lab 8](../labs/08-timeline-and-file-maintenance.md) for planning and file maintenance. Questions GHF-022 through GHF-035 cover the added material.

## Applying the topics

Practice Git integration in [lab 9](../labs/09-merge-conflicts.md), inspect a proposed change in [lab 10](../labs/10-review-a-pull-request.md), and compare evidence in the [insights guide](insights-and-security-tools.md). The [scenario workbook](../practice/scenario-workbook.md) asks you to explain decisions and then change them when the situation changes.
