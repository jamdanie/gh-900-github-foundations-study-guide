Source: [Microsoft Learn GH-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900).

## Choose your next session

Start with Git basics because they support the other exercises. Then follow your missed answers. A small domain still matters, especially if its terms are unfamiliar.

| If you cannot explain… | Practice this |
| --- | --- |
| What remains local after a commit | Make a branch, commit, and inspect the remote before pushing |
| Why an issue and PR are different | Open an issue for a documentation change, then propose the change in a PR |
| Why a test runs automatically | Find the workflow event, job, runner, and step |
| Which environment can execute code | Compare your local editor, github.dev, and Codespaces |
| Who should receive repository access | Use the permission scenarios in lab 4 |
| Why a board item moved | Examine the project's built-in workflow and the linked issue |

## Scope of the extra practice

The runnable Python checks, detailed Git recovery commands, and deployment-environment exercise go beyond recognizing feature names. Use them to make the concepts concrete. Do not treat every command flag in this repo as an exam objective.

The 35-question set samples all seven domains equally. It is deliberately not weighted like the exam and is not a comprehensive readiness assessment. Use the official outline to check coverage, including topics you did not miss in this small set.
