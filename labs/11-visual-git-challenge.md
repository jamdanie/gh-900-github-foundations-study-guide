# Lab 11: Predict, observe, explain

[Table of contents](../CONTENTS.md)

Goal: connect a command to a visible change in repository history. Begin in [Learn Git Branching](https://learngitbranching.js.org/), which simulates Git in your browser, or use [Oh My Git!](https://ohmygit.org/) if you prefer its downloadable card interface.

## Use the exercise's own instructions

1. Choose an introductory commit or branch exercise. Read its starting state and goal.
2. Before each action, predict whether it will create a commit, create a branch, change your current branch, or combine work.
3. Perform one action using the tool's supported interface.
4. Look at the graph. Identify what moved and what stayed in place.
5. If your prediction was wrong, explain the difference before moving on.

Use the command syntax shown by the exercise. A teaching simulator may support a narrower command set than your installed Git. Do not assume every simulator command or shortcut is a real Git command.

## Record a useful result

Write the starting state, your prediction, the action, and your observation. A screenshot without an explanation is not enough. A suitable statement is: “I expected a new commit, but this action only moved the current branch selection.” Use that wording only if it matches what you observed.

Then change one condition: switch which branch you are on, or choose a different starting point within the exercise. Predict the new result.

## Transfer the idea

Complete [lab 12](12-read-a-local-history.md) in a new local folder. Compare its history with the simulator. Local Git requires you to edit and stage files; a simulator may simplify those parts.

Completion means you can explain one branch operation in your own words. It does not require a particular game score. Advanced rebase and history-rewriting levels are optional enrichment, not a requirement to complete this beginner lab.

Sources: the linked tool maintainers. Resource comparison: [visual learning guide](../docs/visual-learning-resources.md).

## Check the result before moving on

Can you explain one unexpected graph change?

Describe your prediction, the action, and what moved. Translate the result into a repository concept rather than only naming a game control.

If you get stuck: If the tool rejects a command, read its supported interface. Compare with installed Git before claiming the command itself is invalid.

Use the [troubleshooting guide](../docs/troubleshooting-first-steps.md) to choose an inspection and the [challenge workbook](../practice/troubleshooting-challenges.md) to practice the reasoning without changing a live repository.
