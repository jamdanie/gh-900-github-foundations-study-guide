# Security

This repository is educational material and small local practice scripts. Never commit tokens, passwords, private keys, or personal account screenshots.

For a non-sensitive documentation correction, open an issue. Do not post an exposed credential in an issue. Revoke it through its provider and follow GitHub's guidance for removing sensitive data from repository history.

Use GitHub's private vulnerability reporting option if it is enabled for this repository. Do not assume that this file alone enables private reporting.
